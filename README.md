# 水上base v2.2｜西条・新居浜 オンライン広域ワールド

## 今回の統合
- v2.1の7800×4800px広域マップ、600pxチャンク描画、地形・木・川・橋・道路・4拠点（西条市役所、水上塗装、新居浜市役所、水上ドーム）
- v2.1と同じ125px/秒の歩行速度。地面タップ・クリックとWASD・矢印キー、ミニマップ移動。
- ルーム指定がない場合は全員自動的に共通の `main` ルームへ入る。同時10人まで。
- 写真の丸アイコン表示（48px）、写真の切り抜き・名前の保存。手足のアニメは付けない。
- オンライン吹き出しチャット80文字・30秒消滅。
- 共有ログハウス（配置・収納・引っ越し、簡易建築判定、同じ場所に二軒置けない）。
- 簡易釣り：小70%、中25.5%、マグロ4.2%、シーラカンス0.3%。
- 3色のリアルタイム共同お絵描き。
- 140文字＋写真最大3枚の市役所別掲示板。投稿・閲覧・本人削除・X/LINE共有・Instagram用カード。

## 注意・今後の課題
- 大規模マップの地形はゲーム用の模式図であり、実際の新居浜・西条の道路、河川、敷地の精密なGIS再現ではありません。
- 同時参加10人が上限。一般公開前に認証、投稿管理、モデレーション、レート制限を強化してください。
- 掲示板SQLite、家、お絵描きはRender無料インスタンスの再起動や再デプロイで失われる場合があります。永続DBと画像ストレージへの移行が必要です。
- 地形・木の位置はクライアント側の描画データ。サーバー側では地形の主要形状と施設/家の衝突を検証しており、すべての木の衝突まではまだ同期していません。
- スマホの操作画面は用意しているが、iPhone/Android実機検証は今後の課題。
- 同じブラウザの2タブで同一の所有トークンを使っている場合、同一所有者とみなされます。
