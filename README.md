# 水上base みんなの広場 — v1.2 立ち話モード

最大10人が同じ招待URLでアクセスし、互いの移動とチャットをリアルタイムで共有する試作です。自分は白丸、ほかの参加者は黒丸。吹き出しは各キャラクター最大6件、投稿後15秒で消えます。

## パソコンで動かす

Python 3.10以上を用意し、フォルダ内で以下を実行：

```bash
pip install -r requirements.txt
python server.py
```

ブラウザで `http://localhost:8080` を開いてください。2つのタブで動作確認できます。

## 別の場所の人とオンライン共有するには

このアプリを外部公開できるサーバーに配置する必要があります。例：RenderのWeb ServiceやさくらVPSなど。Docker対応のホスティングなら、このフォルダをGitHubリポジトリに入れDockerfileでデプロイできます。公開URLを開くと一意なルームURLが生成され、「招待URLをコピー」で相手を招待できます。HTTPS公開時はWebSocketも自動でwssを使用します。

### Renderでの例
1. このフォルダをGitHubの新しい非公開リポジトリへアップロードする。
2. Renderで「New → Web Service」からリポジトリを連携。
3. Runtime/LanguageをDockerにしてデプロイする（料金・スリープ条件は契約時に確認）。
4. 発行されたHTTPSのURLを開き、招待URLを相手に送る。

**注意** 公開サーバー側に管理者パスワード・レート制限・監視等を追加していないため、あくまで少人数の短期間の試験向けです。全体への公開や業務上の機密情報の入力には使用しないでください。より限定的な利用が必要なら、環境変数 `ROOM_PASSWORD` に共有パスワードを設定し、招待リンクのURLパラメータ `password=` で渡せますが、URL共有・履歴に残るため本格的な認証には向きません。

## 構成
- `server.py` : aiohttpでHTTP + WebSocketサーバー。ルーム当たり10人まで。
- `public/` : PC/スマホ用のHTML・CSS・JavaScript。
- `Dockerfile` : クラウド公開用。

チャットはサーバーに永続保存しません。再接続すると表示も消えます。サービス化する前に認証、乱用防止、プライバシー、負荷・同時接続の設計が必要です。

## 10人版で変更した箇所
- 1部屋の定員を2人から10人に拡張（11人目は入室できません）。
- 入室時の丸の初期位置を2列ではなく5個×2列の配置にして、重なりを抑えています。
- 参加人数表示、ページ内の案内を10人用に変更しています。
- 誰の画面でも「自分＝白丸、ほかの9人＝黒丸」と表示します。
- チャット吹き出しは各キャラ最大6件、各発言15秒で消えます。
- ローカルでの実装確認と、実際のネットワークを介した10人同時操作の負荷試験は別です。後者は公開環境で実施してください。

## v1.1 — 名前保存・自由な写真アイコン

- 上部の「表示名」を編集するとブラウザに自動保存され、同じブラウザでの次回アクセス時に復元されます。
- 「写真を選ぶ」からJPEG/PNG画像を読み込み、プレビューをドラッグして位置調整、スライダーで拡大してから「この画像で決定」を押してください。
- ブラウザ内で128×128ピクセル程度のJPEGに変換し、サーバーへ送信します。**元の写真ファイルはアップロードしません。**
- 参加者ごとの丸アイコン・名前・吹き出しをリアルタイム同期します。丸アイコンはCSSで丸く切り抜いて表示します。画像未設定なら従来の白丸／黒丸です。
- 名前と変換済みアイコンは、そのブラウザのlocalStorageに保存されます。別端末・別ブラウザへの引継ぎやアカウント同期はありません。データ削除やプライベートブラウズでは消える場合があります。
- サーバーは接続中のアイコンのみメモリ保持し、永続ストレージには保存しません。サーバー停止・切断時には消えますが、再接続時にブラウザから送信し直します。
- 不特定多数への公開向けではありません。写真と名前は同じ部屋の全員の端末に送信されます。個人情報や公開したくない画像は使わないでください。

テスト済み：Python構文・JavaScript構文、WebSocketの10接続／11人目の入室拒否、名前・画像・チャットの配信。実機の画像切り抜き操作・外部公開環境での10人同時操作については未検証です。


## v1.2 — 立ち話モード（履歴のない広場）
- 右側のLIVE CHAT履歴パネルを撤去し、広場を横幅いっぱいに拡大しました。
- 入力欄は広場のすぐ下に移動しました。参加人数は上部に表示します。
- 吹き出しは各キャラクター最大6件、投稿から約15秒でDOMから削除されます。過去の発言を画面内に履歴として残しません。
- サーバーは引き続きチャット本文を保存せず、同じ部屋の現在の参加者へ配信するだけです。
- 写真アイコン、名前の保存、10人定員、移動、招待URLなど既存機能は維持します。
- 注意：履歴を残さない設計でも、参加者によるスクリーンショットや録画、外部通信記録までは防止できません。

### 以前の版から差し替える場合
1. 実行中のPowerShellで `Ctrl + C` を押してサーバーを止めます。
2. **このZIPを解凍した新しいフォルダ**内でPowerShellを開きます。
3. 既にPythonと必要なライブラリをインストール済みなら、次を実行します。
   `& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" server.py`
4. `http://localhost:8080` を開いて `Ctrl + Shift + R` で強制更新します。
5. 以前と同じブラウザ・同じlocalhostなら名前とアイコンのブラウザ保存は引き継がれます。
